# Synthetix Host

Sitio estático (GitHub Pages). La home está hecha con React y se sirve ya compilada desde `assets/js/dist`, así que **no necesitas compilar nada para publicarlo**.

## Editar el código fuente
- `src/` contiene los componentes de React, el globo 3D (`globe.js`), los iconos y el catálogo (`data.js`).
- Para recompilar: `npm install` y luego `npm run build` (sube también la carpeta `assets/js/dist`).
- Estilos: `assets/css/styles.css`. Login, registro, recuperación y panel usan JS en `assets/js/`.
